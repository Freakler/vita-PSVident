# PSVident

An Application that displays various Information of your Console

## Controls
CROSS - Refresh Page <br>
SQUARE - Censored Mode <br>
TRIANGLE - Raw Values Mode <br>
CIRCLE -Reset <br>
RIGHT or R - Next Page <br>
LEFT or L - Previous Page <br>
DOWN (hold for 2s) - Save Report ("ux0:data/psvident_XX-XXXXXXXX-XXXXXXX.txt") <br>
